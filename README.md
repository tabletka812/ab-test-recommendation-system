# A/B-тест системы персональных рекомендаций

Анализ A/B-эксперимента: влияние персонализированной рекомендательной системы на средний чек и конверсию интернет-магазина (n = 83 470 пользователей).

**Главный вывод:** система не достигла заявленной цели по росту среднего чека (+2.62% при пороге 3%), но дала +16.5% выручки на пользователя за счёт сильного роста конверсии. Рекомендация: внедрять, с пересмотром главной метрики для будущих тестов.

[Ноутбук с анализом]([notebooks/ab_test_analysis.ipynb](https://github.com/tabletka812/ab-test-recommendation-system/blob/main/notebooks/sample.ipynb)) · [Презентация]([reports/presentation.pdf](https://github.com/tabletka812/ab-test-recommendation-system/blob/main/reports/Презентация.pdf))

## Контекст

Онлайн-сервис по продаже товаров внедряет персонализированную систему рекомендаций. Пользователи тестовой группы в течение 7 дней использовал новую систему рекомендаций. Стояла задача определить, увеличивает ли система средний чек и вовлечённость пользователей, и ответить на вопрос: раскатывать ли её на всех пользователей.

Данные сгенерированы сервисом [ab-tests.ru](https://ab-tests.ru) (ключ генерации: `999543812`).

## Дизайн эксперимента

| Параметр | Значение |
|---|---|
| Главная метрика | Средний чек клиента за неделю |
| Второстепенная метрика | Конверсия в покупку |
| H0| Средний чек не изменится|
| H1 | Средний чек изменится |
| α (ошибка I рода) | 0.01 |
| β (ошибка II рода) | 0.1 (мощность 0.9) |
| MDE | +3% к среднему чеку |
| Длительность | 7 дней |
| Сплит | 50/50, случайный (42 029 / 41 441) |

## Ключевые результаты

| Метрика | Контроль | Тест | Эффект | Критерий | p-value |
|---|---|---|---|---|---|
| Средний чек (покупатели) | 5 512 ₽ | 5 657 ₽ | +2.62% | t тест стьюдента | 3.3·10⁻⁴ |
| Конверсия в покупку | 21.07% | 23.93% |+2.86 п.п. (+13.6%) | z-тест | 4.9·10⁻²³ | 

## Выводы

Обе метрики показали статистически значимый рост (p-value < α = 0.01), но эффект по главной метрике - среднему чеку, оказался ниже минимального порога, заложенного бизнесом (2.62% < 3%).

Выручку на пользователя можно разложить на две части: сколько людей покупает (конверсия) и на какую сумму (средний чек). Система почти не изменила размер покупки, зато покупать стало заметно больше людей. Именно за счёт роста конверсии выручка на пользователя выросла на 16.5%.

Рекомендация: систему стоит внедрять на всех пользователей. Цель по среднему чеку формально не достигнута, но суммарный эффект на выручку большой.

## Что использовано

Python: pandas, numpy, scipy, statsmodels, matplotlib
A/B-тестирование: дизайн эксперимента (α, β), проверка сплита и качества данных, анализ выбросов (IQR)
Статистика: проверка гипотез, t-тест стьюдента, z-тест, выбор критерия под тип метрики
Продуктовая аналитика: декомпозиция метрик (ARPU = конверсия × средний чек), выводы и рекомендации для бизнеса
